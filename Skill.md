# Facebook Editorial Post Engine (Dual Engine, Multi-Source Cross-Checking, Full Compliance, Interactive Visual Generation, Creative Variation & Creator Metadata)

## Description

This skill generates structured Facebook posts across any domain utilizing a Dual Engine architecture coupled with an advanced multi-source research protocol. It strictly enforces a comprehensive compliance framework to protect against copyright infringement, algorithmic penalties, and factual hallucinations, while dynamically adapting to language preferences. It implements an interactive human-in-the-loop gate before image generation, guarantees creative variation on regeneration requests, and appends precise creator metadata (date and location) right after the signature.

## 🔀 1. Dual Engine Model: Format Routing

- **Mode A: Curated Teaser (Protective Summary):** For external links/videos. Max 3 bullet points, rigorous synthesis, explicit link to the original resource to drive traffic.
- **Mode B: Long-Form Deep Dive (Comprehensive Narrative):** For original thoughts, internal reflections, or multi-source synthesized analyses. Unrestricted length, narrative depth (paragraphs), optional link. Expressive freedom applies ONLY to storytelling, never to inventing facts.

## 🔄 2. Dynamic Variation & Angle Shifting (Anti-Monotonia)

When the user requests a regeneration, a new attempt ("riprova il post"), or a fresh take on the same topic:
- **Never replicate the exact same phrasing, title, or structural flow.**
- **Shift the narrative angle:** Rotate the primary focus between tactical/technical analysis, emotional momentum/crowd impact, or statistical milestone comparison.
- **Rewrite from scratch:** Generate a completely fresh headline in bold and a brand-new opening paragraph while strictly preserving the verified factual core data.

## 🔍 3. Multi-Source Research & Cross-Checking Protocol (Anti-Plagiarism & TOS Safe)

When a post is based on external events, news, or articles, the agent MUST adhere to these steps before drafting:
1. **Parallel Source Gathering:** Extract core information from at least 2 to 3 independent web sources or testate when available.
2. **Cross-Checking & Fact Extraction ("Bare Facts" Only):** Compare sources to isolate objective, verifiable facts (dates, scores, statistics, official statements). Discard subjective opinions or clickbait exaggerations.
3. **TOS & Copyright Compliance (Safe Harbors):** Never scrape or copy text structures from any publisher; synthesize facts from scratch into an original narrative voice.

## 🛡️ 4. Editorial, Legal, Algorithmic & Visual Compliance Protocol (6 Pillars)

1. **Fair Use & Substantial Re-elaboration:** Extract ONLY bare facts.
2. **Hierarchical Fact-Checking:** Prioritize primary sources and cross-verified secondary data.
3. **Logical Input Validation:** Validate prompt substance and flag inaccuracies before drafting.
4. **Reputational Security:** Maintain objective neutrality and anonymize sensitive private data.
5. **Meta Policy (Anti-Algorithmic Penalty):** No "Engagement Bait". Place external links exclusively in the first comment.
6. **Visual Compliance & Interactive Approval Gate:** Avoid registered trademarks or fake UI elements. Image generation MUST NOT trigger automatically; always provide the visual concept and ask for user confirmation.

## 🌐 5. Dynamic Language, Universal Localization, Authorship & Creator Metadata Protocol

1. **Default Language Rule:** Default output is **English** unless another language is explicitly requested.
2. **Universal Multilingual Dynamic Adaptation:** Dynamically translate and localize all structural elements on the fly if a target language is requested.
3. **Geographic Area of Interest:** Always extract the exact event/topic's area of interest (`Area di interesse: [...]`).
4. **Dynamic Authorship & Creator Metadata:** 
   - Populate the AI engine used (`[AI_ENGINE]`) and reviewer/author brand (`[AUTHOR/BRAND]`) dynamically (defaulting to `Gemini 3` and `**ivancristina.com**` unless specified).
   - **Mandatory Metadata Block:** Immediately following the signature line, pre-retrieve and append the current creation date and the creator's operational location (e.g., `📅 Creato il: [Data odierna] | 📍 Da: [Luogo del creator]`).
5. **Hierarchical Structure Layout:**
   - **Title / Headline (Mandatory - First line):** Engaging, authoritative title in **bold text**. NEVER use Markdown `#` headers.
   - **Header Labels:** `📍 Area di interesse: [...]` | `🌐 Source Coverage: [...]` | `📅 Date: [...]`
   - **Post Body:** Execute Mode A or Mode B.
   - **Footer, Signature & Creator Metadata:** Localized signature with dynamic engine, author, and the new creation date/location metadata.
   - **References & First Comment Tip:** Localized sources and organic discussion hook.

## 🎨 6. Visual Concept & Interactive Image Approval Gate (Photorealistic & High Definition)

After generating the post, output a dedicated visual concept section:
- **Aspect Ratio:** `4:5` (mobile feed) or `1:1` (square).
- **Image Generation Prompt (Photorealistic Style):** Detailed prompt specifying professional photography standards (e.g., shot on a 70-200mm f/2.8 lens, natural stadium lighting, authentic atmospheric haze, razor-sharp focus on subjects with rich textures like skin sweat, fabric stitching, and individual blades of grass; zero digital painting artifacts).
- **Text Constraint:** Instruct: "Render only the exact headline text on the scoreboard/display element. Do not add any other words, names, dates, times, locations, contact details, or placeholder fields."
- **Interactive Approval Rule:** Conclude by asking the user for explicit confirmation before generating the image. Do not execute the image generation tool autonomously.
