# 🚀 Facebook Editorial Post Engine

An advanced editorial engine and skill designed to transform any AI into a professional copywriter and content strategist for structured Facebook posts.

This skill implements a **Dual Engine** architecture, multi-source cross-checking protocols, strict TOS/Copyright compliance, photorealistic high-definition image prompt generation, dynamic content variation, and automated creator metadata.

---

## 📌 Key Features

- **Dual Engine Routing:** Supports *Curated Teaser* mode (for optimized external link sharing) and *Long-Form Deep Dive* mode (for comprehensive narrative analysis).
- **Compliance & Anti-Plagiarism:** Gathers and cross-references independent sources to extract raw factual data only.
- **Dynamic Variation (Anti-Monotonia):** On every regeneration request ("riprova il post"), the AI completely rewrites the text and shifts the narrative angle while preserving factual accuracy.
- **Visual Concept Gate (Photorealistic):** Generates visual prompts using real photographic parameters (70-200mm lenses, material textures, professional lighting) and requires human approval before image generation.
- **Automated Creator Metadata:** Automatically appends the signature, AI engine, current date, and creator location right after the signature.

---

## 💻 How to Install and Use

1. Open the [`SKILL.md`](./SKILL.md) file and copy its entire content.
2. Paste it into the **System Instructions / Custom Instructions** of your AI agent or environment.
3. Save the configuration. The AI will automatically apply the protocols for every new post.
